# Ноутбук Windows XP — аддон для Garry's Mod

Интерактивный проп ноутбука. Игрок нажимает **E**, камера плавно
подъезжает к экрану, после короткой "загрузки" появляется рабочий стол
в стиле Windows XP: значки, Пуск, панель задач с часами, окна
"Мой компьютер", "Блокнот" и "Internet Explorer" (с настоящим DHTML-браузером).
Выход — клавиша **ESC** или крестик в углу экрана.

## Установка

1. Скопируйте папку `laptop_winxp` целиком в:
   `Garry's Mod/garrysmod/addons/laptop_winxp/`
2. Структура должна выглядеть так:

```
addons/
  laptop_winxp/
    addon.json
    lua/
      entities/
        laptop_winxp/
          init.lua
          cl_init.lua
          shared.lua
```

3. Перезапустите игру/сервер. Сущность появится в меню создания (Q) →
   категория **"Интерактивные пропы"** → **"Ноутбук (Windows XP)"**.
   Либо заспавнить через lua-консоль:
   ```lua
   local e = ents.Create("laptop_winxp")
   e:SetPos(LocalPlayer():GetEyeTrace().HitPos)
   e:Spawn()
   ```

## Настройка модели

По умолчанию используется стандартная модель HL2-монитора
(`models/props_lab/monitor01a.mdl`), чтобы аддон работал у всех без
дополнительного контента. Чтобы использовать модель настоящего
ноутбука, откройте `shared.lua` и замените `ENT.LaptopModel` на путь
к своей модели (например, найденной в Steam Workshop), затем
подстройте `ENT.ScreenOffset` / `ENT.ScreenForwardOffset` под неё.

## Возможности

- Плавный подъезд/отъезд камеры к экрану ноутбука.
- Анимация "загрузки Windows XP" перед рабочим столом.
- Рабочий стол: иконки, окна, Пуск-меню, панель задач с часами.
- "Internet Explorer" на базе DHTML умеет открывать реальные сайты.
- Диалог "Завершение работы".
- Полная блокировка игрока, пока он "сидит" за ноутбуком, с корректным
  восстановлением при отключении/удалении пропа.
